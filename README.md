# Ecommerce Sales Dashboard

## Project Overview
This project analyzes ecommerce sales data using an interactive dashboard to understand sales, profit, product categories, customers, and payment methods.

## Dataset
The project uses two related tables connected through Order ID.

**Sales Table:** Order ID, Amount, Profit, Quantity, Category, Sub-Category, Payment Mode, AOV.

**Order Details Table:** Order ID, City, State, Customer Name, Date.
